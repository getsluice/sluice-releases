# Sluice user guide

Sluice is a free file manager for your servers. It connects over SFTP, SCP, FTP and FTPS, and opens files in its built-in editor or VS Code, with every save uploaded straight back to the server.

This guide is for Sluice 1.3. Sluice is currently for macOS.

## Pages

1. [Getting started](getting-started.md): installing Sluice, opening it the first time, and connecting to your first server.
2. [Sites](sites.md): the site form, field by field, for SFTP, SCP and FTP, and how to keep sites in folders.
3. [Browsing](browsing.md): tabs, the folder tree, the file list, the path bar, hidden files, sorting, the status bar, and the keyboard.
4. [Editing files](editing.md): double-click editing, which app opens a file, upload on save, and what happens when the server's copy has changed.
5. [Transfers](transfers.md): uploads and downloads, the transfer panel, pausing and retrying, and reconnecting after a drop.
6. [Terminal and Find](terminal-and-find.md): a terminal on the server, and finding files by name.
7. [Settings](settings.md): every setting, pane by pane.
8. [Security and privacy](security-and-privacy.md): server identity checks, certificates, plain FTP, saved passwords, and what Sluice sends over the internet.
9. [Troubleshooting](troubleshooting.md): what Sluice's messages mean, what to do about them, and how to report a problem.

## What works today

| Protocol | Status |
| --- | --- |
| SFTP | Works today. |
| SCP | Works today, for servers without SFTP. |
| FTP and FTPS | Works today. FTPS is the default for FTP sites. |
| WebDAV | Coming later. |
| Amazon S3 and S3-compatible storage | Coming later. |
